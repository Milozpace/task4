# 代码修改说明

## 防御性代码
- 检查并优化了每一个方法
- 主要是添加了可以调用对应函数的条件判断
- 以及在不同的执行情况下对应的处理情况，让内部状态清晰和可管理
- 理解并优化了析构函数的处理

## 取图方法优化
- 理解并清晰了该方法实现的三个功能——从相机获得frame，转为bgr，以及freebuffer
- 当前两步失败时让img release，并无法调用imshow
- 针对链路的多种情况做出了对应的处理措施
    - cvtColor异常 ——  保证FreeImageBuffer要执行而不是直接结束函数执行


## 接口封装
- 把初始化、反初始化和枚举封装进相机中
- 分别优化了它们的调用安全性

## 返回值优化
- 保证了每一种情况对应的返回值直观明了，正确输出状态码
